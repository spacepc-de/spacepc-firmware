# SpacePC Home Assistant Display

Firmware for a local, Home Assistant-managed 7.5-inch e-paper dashboard.
Home Assistant selects entities and sends a compact widget layout to the
display through the SpacePC local API. No cloud service or MQTT broker is
required.

## Confirmed hardware target

- Good Display ESP32-L controller
- DESPI-C02 adapter
- Good Display GDEY075Z08, 7.5 inch, 800 × 480, black/white/red

The firmware currently supports value, status and graph widgets. The display
uses full refreshes and enforces a five-minute minimum (ten minutes by default
in Home Assistant) to protect the panel. It is a
dedicated always-connected display firmware and is separate from the SpacePC
weather display project.

After flashing, connect to the `SpacePC-spacepc-homea-*-*` setup network using
password `spacepcsetup`, then enter the Wi-Fi credentials. Home
Assistant discovers the device over mDNS. Open the integration's Configure
dialog to choose the displayed entities and widget types.

## Local API extension

`GET /api/v1/info` advertises display dimensions and supported widgets.
`PUT /api/v1/display` accepts the layout generated by the SpacePC Home
Assistant integration.
