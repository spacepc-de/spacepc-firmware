# SpacePC firmware

This repository currently contains one deliberately empty firmware project
used to verify the SpacePC build and browser-release pipeline.

## Project layout

```text
projects/
  dummy-test/
scripts/
  prepare-release.mjs
```

The program has empty `setup()` and `loop()` functions. It does not drive
outputs, sensors, motors or LEDs. The temporary build target is the generic
`esp32-s3-devkitc-1`.

## Local build

Install PlatformIO Core and build one project:

```sh
python3 -m pip install platformio==6.1.18
cd projects/dummy-test
pio run
```

## Continuous integration

Every push and pull request compiles the dummy project. Toolchain and platform
versions are pinned for reproducible builds.

## Firmware releases

Test release tags use `dummy-test-v<semantic-version>`, for example:

```sh
git tag dummy-test-v0.1.0
git push origin dummy-test-v0.1.0
```

The release workflow:

1. compiles the dummy project;
2. reads the flash offsets generated by the build;
3. creates an ESP Web Tools manifest;
4. calculates SHA-256 checksums;
5. publishes immutable GitHub Release assets.

Never replace assets belonging to an existing version. Test every release on
the exact compatible board revision before marking it stable on spacepc.dev.

## Safety

This dummy firmware makes no electrical claims and contains no production pin
assignments. Do not use it as functional device firmware.
