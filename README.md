# SpacePC firmware

This monorepo contains firmware projects for the SpacePC maker platform.
Every project builds independently while sharing small, hardware-neutral
components from `shared/lib`.

## Project layout

```text
projects/
  smart-fan/
  room-sensor/
  epaper-weather-display/
  bedside-lamp/
shared/
  lib/SpacePCCommon/
scripts/
  prepare-release.mjs
```

The current programs are deliberately minimal compile-tested scaffolds. They
do not drive outputs, sensors, motors or LEDs. The temporary build target is
the generic `esp32-s3-devkitc-1`; replace it only after the actual SpacePC
board revision, flash layout and pins have been verified.

## Local build

Install PlatformIO Core and build one project:

```sh
python3 -m pip install platformio==6.1.18
cd projects/smart-fan
pio run
```

## Continuous integration

Every push and pull request compiles all projects. Toolchain and platform
versions are pinned for reproducible builds.

## Firmware releases

Tags use `<project>-v<semantic-version>`, for example:

```sh
git tag smart-fan-v0.1.0
git push origin smart-fan-v0.1.0
```

The release workflow:

1. compiles the selected project;
2. reads the flash offsets generated by the build;
3. creates an ESP Web Tools manifest;
4. calculates SHA-256 checksums;
5. publishes immutable GitHub Release assets.

Never replace assets belonging to an existing version. Test every release on
the exact compatible board revision before marking it stable on spacepc.dev.

## Safety

These scaffolds make no electrical claims and contain no production pin
assignments. Do not connect motors, heaters, batteries, high-current LEDs or
other loads until the hardware revision and its limits are documented and
reviewed.
